# libft

## Description

**目標**

C言語の指定された標準ライブラリ関数を自作する。

**概要**

libcの基本的な関数を再実装することで、低レベルなメモリ操作や文字列の仕組みへの理解を深める。

## Instructions

### コンパイル

カレントディレクトリが `libft` の状態で下記コマンドを実行するとビルドができる。

```bash
make
```

### インストール

1. ターミナルを開く
2. プロジェクトのリポジトリをクローンする

```bash
git clone git@vogsphere-v2.42tokyo.jp:vogsphere/intra-uuid-b2d05c74-def0-4e7a-8fea-15898c5a7a5d-7383354-rnagai
```

3. クローンしたディレクトリに入る

```bash
cd libft
```

### 実行

`libft.a` はスタティックライブラリであるため単体での実行はできません。使用したいプロジェクトに `libft.a` をリンクする形で使用してください。

### 文字列操作
 
| 関数 | 説明 |
|------|------|
| `ft_strlen` | 文字列の長さを返す |
| `ft_strchr` | 文字列から指定した文字を先頭から検索する |
| `ft_strrchr` | 文字列から指定した文字を末尾から検索する |
| `ft_strncmp` | 2つの文字列を指定した文字数だけ比較する |
| `ft_strlcpy` | サイズを指定して文字列をコピーする |
| `ft_strlcat` | サイズを指定して文字列を連結する |
| `ft_strdup` | 文字列を動的メモリに複製して返す |
| `ft_strnstr` | 文字列の中から指定長さ内で部分文字列を検索する |
| `ft_substr` | 文字列の指定位置から指定長さの部分文字列を生成して返す |
| `ft_strjoin` | 2つの文字列を連結した新しい文字列を生成して返す |
| `ft_strtrim` | 文字列の先頭と末尾から指定した文字集合を除去して返す |
| `ft_split` | 指定した区切り文字で文字列を分割し、配列として返す |
| `ft_striteri` | 文字列の各文字にインデックス付きで関数を適用する |
| `ft_strmapi` | 文字列の各文字にインデックス付きで関数を適用した新しい文字列を返す |
